# 两个项目的介绍与导引

点击侧边栏「数据分析」或「政策复盘」首先进入各自独立的介绍页。分别展示产品用途、实际问题、输入与交付、四层执行架构与默认演示材料。

四层是展示视角：任务/口径→Agent编排→程序执行→结果沉淀。AI蓝、程序绿、人工琥珀有文字说明；强调边框表示确认或校验关口，虚线明确后续规划，不表示已实现。

每页只有开始本项目演示这一主操作（顶部与页尾重复同一入口），进入已有下一步体验；可返回介绍。数据分析侧重表格到经营结论，政策复盘侧重客户达成与增量ROI。未发布政策设计、自动监控和经验回流只标为后续。

默认模拟数据和游客固定输入保持，未读取保密归档。账号数据、历史与复杂表格能力保持。手机四层横向节点转纵向排列，不裁切文字。

验证：npm run check:guided-browser覆盖两介绍页、各四层、演示下一步、计算图表、默认政策和390px布局；生产另用真实DeepSeek验收。

## 四层任务叙事（2026-11-13）

两项目统一为产品规划层、Agent编排层、实际执行层、数据回流层。每层独立说明任务开始、处理过程、任务结束和交付；编排层调用实际执行工具并通过反馈推进，两层不是一次性的串行处理。

政策项目范围仅为复盘，不介绍政策设计或经验库闭环。数据回流仅为账号历史留存：成功分析/复盘进入、保存当时问题规则和结果、历史可查可导出。游客不长期保存，失败与澄清不作为成功历史。

## 用户提问与追问（2026-11-13）

介绍页新增两条问答入口：点击预设分析问题，或自由输入问题。两者进入同一Agent理解、澄清、执行校验和回答流程。澄清后用户补充条件回到理解步骤；回答后可继续追问，最近对话传入下一次执行。成功问答按账号逐次保存历史，最近对话与长期历史分别说明。

数据分析提问及结果页的输入区默认展开，面试官可直接提问。政策导入/重算仍是确定的程序核算，不混作自由问答Agent。四层标题与每层任务开始/结束结构保留，默认数据和游客权限不变。
