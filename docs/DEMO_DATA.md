# 默认模拟数据

政策监控默认展示 `data/policy-demo.json`：20个虚构客户、259条消耗记录，政策周期2026-09-25至2026-10-07。覆盖一档、二档、未达成、消耗下降、封顶、零现金和缺数场景。

默认客户达成率75%，base加权达成率77.112135%，获政策返货客户14个，增量ROI为4.081436。页面明确标注模拟数据，默认政策没有内网文档链接。

没有保存输入的新账号自动加载模拟数据。自行上传后读取该账号的输入，继续保持账号隔离；Git部署不会把其他账号输入当作默认数据。开发工作台与生产用户的历史政策输入、报告和图表已迁出提供访问的目录，保留在本机忽略Git的私有归档中。

默认数据及浏览器回归仅使用模拟文件，不从本机真实Excel恢复默认展示。真实数据、密钥、账号文件、历史归档均不进入Git或Vercel部署包。
