# 面试演示体验

侧边栏和手机导航仅保留「数据分析」「政策复盘」两个入口。默认模拟数据随应用保留，无需上传即可体验。

数据分析：查看销售数据概览 → 下一步确认数据口径 → 运行演示分析 → 查看真实计算结果、图表和依据 → 继续政策复盘。步骤为文字状态，不可点击跳页。

政策复盘：了解20个客户的模拟数据与规则 → 查看客户数/base加权达成率和ROI → 查看客户、过程、问答和导出。默认通过只读演示参数读取固定模拟数据，不覆盖个人上传；问答与导出使用同一演示范围。

历史、CSV上传、复杂Excel准备、样例切换和自动评测保留在流程内的折叠次级操作中。游客仍不可上传、修改规则或访问账号历史。默认政策演示不允许重算个人输入；修改个人口径需要先切换到自己的上传数据。

此前未发布的本地政策设计模块未纳入此版生产发布，源码保持。既有政策计算和保密归档保持。

验证入口：npm run check:guided-browser，使用独立测试服务和模型桩验证两个导航入口、下一步、分析图表、模拟政策及390px布局；真实模型另作公网验收。
