# 两个项目的介绍与导引

点击侧边栏「数据分析」或「政策复盘」首先进入各自独立的介绍页。分别展示产品用途、实际问题、输入与交付、四层执行架构与默认演示材料。

四层是展示视角：任务/口径→Agent编排→程序执行→结果沉淀。AI蓝、程序绿、人工琥珀有文字说明；强调边框表示确认或校验关口，虚线明确后续规划，不表示已实现。

每页只有开始本项目演示这一主操作（顶部与页尾重复同一入口），进入已有下一步体验；可返回介绍。数据分析侧重表格到经营结论，政策复盘侧重客户达成与增量ROI。未发布政策设计、自动监控和经验回流只标为后续。

默认模拟数据和游客固定输入保持，未读取保密归档。账号数据、历史与复杂表格能力保持。手机四层横向节点转纵向排列，不裁切文字。

验证：npm run check:guided-browser覆盖两介绍页、各四层、演示下一步、计算图表、默认政策和390px布局；生产另用真实DeepSeek验收。
