# 游客体验与账号历史

首页可以直接进入游客体验，无需账号密码；顶部可进入登录，登录页也可返回游客体验。

## 游客

- 支持销售、订单、广告样例预览及AI问答；政策模块固定展示20客户的模拟政策。
- 服务端自行加载模拟输入，不采用游客请求中提供的上传明细、类型映射或政策规则。
- 上传、政策重算/解析、自动评测及历史功能需要登录。游客的历史页只显示登录提示。
- 每次游客会话有效2小时，最多接受10次分析请求；公共接口另有共享调用额度及并发上限。额度用尽或服务繁忙时可稍后重试或登录。
- 游客图表放在独立临时目录，其他游客不能访问；会话过期后不可访问，并由后台定期清理。游客结论不长期保存。

## 登录用户

成功的基础分析、政策问答以及政策导入/重算自动保存到「历史分析」。澄清、失败请求和自动评测不保存为业务结论。保存失败时会显示提示，当前生成的结论仍可查看。

历史列表支持模块、关键词、日期筛选和分页；详情保留问题、答案、证据表、执行步骤与当时政策口径。刷新或重启后端后仍可查看。查看历史不会重新计算或替换当前数据。

基础分析保存数据源名称、字段、行数及输入指纹，不复制整张原始表。政策复盘保存当时规则、截止日、汇总、客户达成与趋势，排除原始每日客户明细。历史图表使用独立副本，避免后续分析或原图表变化影响历史。

详情可下载Markdown、JSON及历史图表。删除需要页面再次确认，会删除该条历史及其历史图表副本；当前上传与其他历史保持。删除无法恢复。记录长期保留，未配置自动过期。

数据仍按账号隔离，同一个账号的使用者共享历史。此前没有保存的结论不自动补录，也不会读取本地保密归档。

## 运行与验证

存储位于本机各账号独立数据目录的 `history/<id>/record.json`，图表副本为同目录 `chart.svg`；运行数据不上传Git或Vercel。当前后端仍依赖电脑在线。

`npm test` 包含游客访问、数据隔离、保存去重、重启读取、快照稳定与删除验证。`npm run check:guest-history-browser` 使用独立测试账号和模型测试桩验证完整页面交互、刷新、图表、导出、删除及390px窄屏；该浏览器测试不计为真实模型连通验证。
